# Santana Auto Mecânica — Projeto Web

Projeto exemplo em Spring Boot + Thymeleaf para uma oficina mecânica (não trabalha com parte elétrica nem com 4x4).

Como executar:

```bash
mvn spring-boot:run
```

A aplicação roda em `http://localhost:8080`.

Admin:
- Usuário: `admin`
- Senha: `admin`

H2 console em `http://localhost:8080/h2-console` (JDBC URL: `jdbc:h2:mem:santana`).
